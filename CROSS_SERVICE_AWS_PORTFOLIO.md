# Cross-Service AWS Portfolio

This portfolio covers public AWS documentation, tutorials, articles, and developer-education work beyond my standalone Amazon S3 documentation portfolio. It includes S3 only where S3 was one part of a broader cross-service initiative. The contribution type varies by project and is stated conservatively.
